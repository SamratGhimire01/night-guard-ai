# Native review: 30 real Romanized-Nepali replies (filled in 2026-10-01)

Names, phone numbers and emails are replaced with [NAME], [PHONE], [EMAIL].

### Key Issues Found Across Responses:

1. **Unnatural Word-for-Word Translations:** Phrases like *"Sunera man chhuttiyo"* (literal translation of "I'm sorry to hear that") sound completely absurd in Nepali. Native receptionists say *"Aha, garo bhayecha"* or *"Aha, dukhi lagyo"*.
2. **Hindi / Literal Terms:** Using terms like *"khoon"* instead of *"ragat"*, *"bukha"* instead of *"jwaro"*, and *"dard"* instead of *"dukhai"* makes the text sound Hindi-influenced rather than conversational Romanized-Nepali.
3. **Overly Robotic AI Leakage:** Phrases like *"configured bhayeko chaina"* or *"sacchai ko manche"* sound like a machine breaking character. A receptionist simply says *"rekord ma xaina"* and *"front desk/staff le contact garnuhunxa"*.
4. **Consistency in Spelling:** Mixing strict formal spelling (`chha`, `chhan`, `hunchha`) with casual messaging shortcuts (`xa`, `hunxa`) in the same system prompt creates an awkward middle ground. Receptionists texting on WhatsApp/Viber usually type clean, semi-formal, natural Romanized Nepali (`cha`, `garchu`, `huncha`).
