# Situation sheet: how a real receptionist would reply

**What this is.** Sixty situations that happen in every business: a clinic, a trekking agency, a salon, a shop, a
school. Each one has a customer message and **my draft** in Romanized Nepali. I'm not a native speaker, so the drafts
are a starting point, not the answer.

**What to do.** For each situation, write how **you** would really text back on WhatsApp if you worked the front
desk. Write it on the `Your version:` line.
- If my draft is already natural, write `OK`.
- If a situation is wrong or never happens, write `SKIP` and say why.
- Use your own spelling (xa/cha, vayo/bhayo, whatever you'd really type).
- Keep the placeholders exactly as they are: `{SERVICE}`, `{PRICE}`, `{TIME}`, `{DATE}`, `{NAME}`. The app fills
  in the real values for each business.

Your versions become the examples the assistant copies for every business. Fifteen situations at a time is fine.
